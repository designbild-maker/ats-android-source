# ATS для Android

ATS — клиент для личного VPN-сервера на основе ядра Xray. Российские сайты открываются
напрямую, остальные — через защищённый сервер.

## Основа и лицензия

ATS — модифицированная версия [v2rayNG](https://github.com/2dust/v2rayNG) 2.3.14
(© 2dust и участники проекта), распространяется под лицензией **GPL-3.0** (см. `LICENSE`).
Исходный код каждой сборки прикладывается к её релизу (`ATS-source-N.zip`) и публикуется в открытом репозитории [ats-android-source](https://github.com/designbild-maker/ats-android-source).

## Изменения относительно v2rayNG

- Название ATS, идентификатор приложения `com.ats.connect`, своя иконка и цвета (тёмная тема, мятный акцент).
- Настройки по умолчанию при первом запуске:
  - фрагментация TLS (tlshello, длина 50-100, интервал 10-20);
  - только IPv4;
  - маршрутизация «Россия напрямую»: российские домены и IP — напрямую, остальное — через сервер;
  - DNS для российских сайтов — Яндекс (77.88.8.8);
  - подписки обновляются автоматически раз в 12 часов.
- Свой стартовый экран ATS (`ui/ats/`): большая кнопка подключения, выбор сервера, «Моя подписка»
  (срок и трафик из заголовков подписки 3x-ui), короткие настройки и первый запуск с вводом ключа.
  Полный интерфейс v2rayNG доступен как «Дополнительные настройки».
- Скрыты реклама и проверка обновлений v2rayNG; ссылки поддержки ведут в Telegram ATS.
- Сборка APK и архива исходников — GitHub Actions (`.github/workflows/ats-build.yml`).

## Сборка

Каждый push в ветку `main` запускает сборку. Готовые файлы появляются в разделе **Releases**:
`ATS_<версия>_universal.apk` подходит для любого Android-телефона.
