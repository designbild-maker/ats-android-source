# Бот ATS (@ats_vpn_key_bot)

Выдаёт ключи ATS из панели 3x-ui. Работает на том же сервере, что и панель, только на
стандартной библиотеке Python 3.9+ (ничего доустанавливать не нужно).

## Что умеет

- **Пользователь:** «Получить доступ» → запрос администратору; «Моя подписка» (сколько дней
  осталось, трафик, ссылка-ключ); «Скачать приложение» (APK); «Поддержка» — любое сообщение
  пересылается администратору. За 3 дня и за 1 день до окончания бот напоминает о продлении.
- **Администратор:** кнопки «1 / 3 / 6 / 12 месяцев» или «Отклонить» под каждым запросом;
  бот создаёт клиента во всех подключениях ATS (одна ссылка подписки, лимит устройств) или
  продлевает существующего. Ответ в поддержку — ответить на пересланное сообщение.
  Команды: `/admin`, `/check`, `/users`, `/give <id> <месяцев>`. Чтобы бот раздавал
  приложение, пришлите ему APK-файл.
- Оплата (Telegram Stars) — позже.

## Установка и обновление

```bash
curl -fsSL https://raw.githubusercontent.com/designbild-maker/ats-android-source/main/bot/install.sh | sudo bash
```

Повторный запуск обновляет бота и сохраняет настройки. Ввести настройки заново:
`... | sudo RECONFIGURE=1 bash`. Настройки: `/opt/ats-bot/.env` (доступ только у root и бота).

Полезное: `sudo systemctl status ats-bot`, `sudo journalctl -u ats-bot -f`.

Лимит устройств в 3x-ui работает, только если в меню `x-ui` включено «IP Limit Management» (fail2ban).
